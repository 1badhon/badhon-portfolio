What is Computer Networking?

Computer networking is the process of connecting computers and other devices so they can communicate and share information.

A network can contain computers, switches, routers, servers and other networking devices.

🌐 Networking Basics
Page 02

IP Address

An IP address is a logical address used to identify a device on a network.

IPv4 addresses are written using four decimal numbers separated by dots.

💻 IPv4 • Addressing
Page 03

Router vs Switch

A switch mainly connects devices inside a local network.

A router connects different networks and forwards packets between them.

📡 Router • 🔀 Switch
Page 04

Subnetting

Subnetting divides a network into smaller logical networks.

It helps improve network organization, address management and security.

🧮 Subnetting
Page 05

DHCP & DNS

DHCP can automatically provide network configuration such as IP addresses.

DNS translates domain names into IP addresses so devices can locate services on a network.

⚙️ DHCP • 🌍 DNS

Cisco Packet Tracer is useful for practicing network topologies and basic device configuration.
